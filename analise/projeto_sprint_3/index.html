Sobre o projeto

Este projeto faz uma análise exploratória de dados sobre o comportamento de pedidos de usuários na Instacart, plataforma de entrega de supermercado. O conjunto de dados é composto por cinco tabelas relacionadas (pedidos, produtos, corredores, departamentos e itens por pedido), o que permite investigar padrões de consumo em diferentes níveis de detalhe.

O objetivo é identificar padrões no comportamento de compra dos clientes, como horários e dias de maior volume de pedidos, frequência de recompra, produtos mais populares e hábitos na montagem do carrinho. Esses insights poderiam apoiar decisões de negócio relacionadas a estoque, promoções e logística de entrega.

Para isso, foram aplicadas as seguintes técnicas: pré-processamento de dados (correção de tipagem, tratamento de valores ausentes e remoção de duplicatas), análise exploratória com Pandas e NumPy, visualização de dados com Matplotlib e agregações com groupby e merge para calcular métricas como a taxa de recompra por produto e por cliente.
