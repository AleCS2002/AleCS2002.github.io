Projeto Final - Sprint 11

Sobre o projeto

O projeto consiste em um estudo de caso de logs de um aplicativo, onde realizamos uma análise de comportamento por teste A/A/B para troca de fonte.

Foi desenvolvido como parte do curso de Análise de Dados da TripleTen, com o objetivo de aplicar técnicas de análise exploratória, visualização de dados e storytelling para gerar insights a partir dos dados coletados.
