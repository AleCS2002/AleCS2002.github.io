Projeto Final - Sprint 2

Sobre o projeto

O projeto tem como objetivo compara as prefêrencias musicais em um streaming de música entre habitantes de duas cidades e testar a hipótese que há diferença de atividade entre os usuários de cada cidade conforme o dia da semana.

Foi desenvolvido como parte do curso de Análise de Dados da TripleTen, com o objetivo de aplicar técnicas de análise exploratória, visualização de dados e storytelling para gerar insights a partir dos dados coletados.
