Projeto Integrado - Sprint 1

Sobre o projeto

O projeto consite em uma analise sobre vendas de jogos, levando em consideração fatores como plataforma, gênero, avaliações, regiões, etc... O objetivo é compreender o mercado de jogos e como jogos se tornam sucesso de vendas

Foi feita uma análise exploratória de dados (EDA) para entender o mercado de jogos, utilizando técnicas de visualização de dados, metricas de vendas foram analisadas de forma regional para decobrir o perfil dos jogos mais vendidos, por ultimo, foram testadas hipóteses para identificar certos comportamentos dos usuário.
