Food App Funnel & A/A/B Test

About the project

A food-products startup wanted to know two things: where users drop off before buying, and whether changing the app's font would hurt conversion. I analyzed the app's event logs to map the purchase funnel and ran an A/A/B test to answer both questions. This is the final project of TripleTen's Data Analytics bootcamp.

Key findings

  • Only 47.7% of users who reach the main screen complete a purchase.
  • The biggest drop is the very first step: just 61.9% move from the main screen to the offers screen (a loss of about 38%). After that, retention is much healthier: 81.3% of users who see the offers reach the cart, and 94.8% of those complete payment.
  • The A/A test passed: the two control groups (A1 and A2) showed no significant difference on any funnel event, which supports the random split of users.
  • The new font made no detectable difference: none of the 16 hypothesis tests was significant, even with a Bonferroni-corrected threshold (smallest p-value: 0.078).

Recommendation

  • Ship the new font. There is no evidence that it hurts (or helps) conversion at any step of the funnel.
  • Focus optimization efforts on the main screen → offers screen transition, where most of the potential revenue is lost. It is likely to pay off more than any cosmetic change like the font.

Approach

  • Cleaned about 244K event logs from 7,551 users (Jul 25 – Aug 7, 2019): renamed columns, fixed data types, labeled the experiment groups (A1, A2, B) and removed 413 duplicates (0.17%).
  • Found that data collection was only complete from Aug 1, so earlier logs (1.16% of events) were excluded. This left 7,534 users, evenly split across the three groups (2,484 / 2,513 / 2,537).
  • Built the funnel (main screen → offers → cart → payment) from unique users per event, leaving out the optional Tutorial event.
  • Ran two-proportion z-tests for every funnel event (A1 vs A2, A1 vs B, A2 vs B, and combined controls vs B), applying a Bonferroni correction for multiple comparisons.

Limitations

  • The analysis covers only 7 days of complete data.
  • "No significant difference" is not proof of "no effect": without a power analysis, small effects could have gone undetected.
  • The number of tests used in the correction grew during the analysis (from 12 to 16). Conclusions are unchanged, since the smallest p-value is far above any threshold.
